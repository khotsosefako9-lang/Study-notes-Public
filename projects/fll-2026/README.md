# FIRST LEGO League, Eastern Cape Regional (NMU, 31 Oct 2026)

Client media job, separate from the REACH reels. Uses the `EventReel` composition
(`src/event/EventReel.tsx`): beat-synced cuts, whip and punch transitions, kinetic
titles, lower-third tags, grade, grain and a logo end card. `EventReel` is 1080×1920,
`EventReelWide` is 1920×1080 for YouTube.

- `demo-vertical.json`: 18s pitch demo cut from last year's recap.
- Music: "Raving Energy" by Kevin MacLeod (incompetech.com), CC BY 4.0. Credit the
  artist in the post description.

Shot props: `from` (source seconds), `beats`, focal `x`/`y`, `rate` (slow motion),
`push` (scale start/end), `in` (`cut`, `whip`, `punch`, `flash`).
