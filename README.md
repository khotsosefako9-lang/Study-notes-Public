# Video Editor

Turns raw footage into vertical 40–60 second clips for Reels and TikTok.

Tooling:
- [FFmpeg](https://ffmpeg.org/): cutting, reframing to 9:16, encoding
- [Whisper](https://github.com/openai/whisper): transcription and captions
- [Remotion](https://github.com/remotion-dev/remotion): animated captions and overlays in React
- [MakeMyClip editor](https://github.com/MakeMyClip/editor): clip editing skill
